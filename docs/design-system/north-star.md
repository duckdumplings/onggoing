# 옹라우팅 Design System North Star

> 버전 2.0 · 2026-08-02

## 정체성: 정밀한 디스패치 데스크

옹라우팅의 화면은 화려한 AI 데모가 아니라, 여러 배송 라인의 마감 위험과 운임 근거를
빠르게 발견하고 수정·확정하는 물류 운영 콘솔이다. 지도, 숫자, 작업 순서가 주인공이며
AI는 별도 장식이 아니라 각 업무 필드의 해석과 판단 근거를 돕는다.

| 축 | 원칙 | 화면에서 보이는 결과 |
|---|---|---|
| 톤 | 차분하고 직접적 | 명확한 동사, 과장 없는 상태 문구 |
| 표현 | 정밀하고 검증 가능 | 정렬된 시각·금액, 계산 근거, 출처 시각 |
| 구조 | 예외 우선 | 불가·재검토 라인이 정상보다 먼저 보임 |
| 형태 | 부드럽지만 기능적 | 역할별 shape, 높은 밀도, 충분한 터치 영역 |
| 움직임 | 원인과 결과 연결 | 선택 라인·지도·상세가 같은 맥락으로 전환 |

## Material 3 Expressive를 적용하는 방식

Material 3 Expressive를 시각 테마로 복제하지 않는다. 다음 네 원리를 옹라우팅에 맞춰 쓴다.

1. **Role color**: 고정 색상명이 아니라 surface, container, state 역할로 의미를 유지한다.
2. **Shape hierarchy**: 버튼·칩·입력·패널의 형태를 달리해 행동과 계층을 빠르게 구분한다.
3. **State layer**: hover, focus, selected, disabled를 색과 테두리의 일관된 변화로 알린다.
4. **Adaptive pane**: 화면 폭에 따라 목록, 지도, 상세를 1~3 pane으로 재배치한다.

## 대표 화면 계약

expanded 화면은 다음 흐름을 기본으로 한다.

`예외 우선 라인 목록 → 선택 경로 지도 → 타임라인·운임 근거 → 조건 수정/확정`

compact 화면은 같은 정보를 순서대로 쌓고, 상세는 bottom sheet로 연다. 채팅은 결과를
복제하지 않고 입력·수정의 진입점으로 남는다.

## 품질 판정 질문

- 5초 안에 가장 위험한 라인을 찾을 수 있는가?
- AI가 상차·배송·마감 중 무엇으로 해석했는지 계산 전에 알 수 있는가?
- 견적 금액이 어느 운임표·공식·유류할증에서 나왔는지 한 곳에서 확인 가능한가?
- 목록에서 라인을 선택하면 지도와 타임라인이 같은 대상을 가리키는가?
- 색을 보지 못해도 상태와 다음 행동을 이해할 수 있는가?

하나라도 아니면 장식보다 정보 구조를 먼저 수정한다.
